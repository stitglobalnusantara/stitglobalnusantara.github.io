# Website STIT Global Nusantara

Website statis HTML, CSS, dan JavaScript yang dapat dipublikasikan gratis melalui GitHub Pages.

## Isi folder
- `index.html` — struktur halaman website
- `style.css` — desain dan tampilan responsif
- `script.js` — menu mobile, tombol kembali ke atas, dan navigasi aktif
- `logo.png` — tempatkan logo resmi kampus dengan nama file ini

## Cara memasang logo
Salin logo resmi kampus ke folder ini dan beri nama persis `logo.png`.
Jika logo belum dipasang, website akan menampilkan monogram STIT sebagai pengganti.

## Data yang WAJIB dilengkapi sebelum dipublikasikan
Cari teks petunjuk di `index.html`, lalu ganti dengan data resmi:
- Nama resmi program studi dan jenjangnya
- Alamat kampus
- Nomor WhatsApp/telepon
- Email resmi
- Tautan media sosial
- Tautan formulir PMB Google Forms
- Deskripsi profil, sejarah, visi, dan misi kampus
- Berita dan foto kegiatan asli

Template ini tidak mengarang data institusi. Konten yang belum diberikan ditandai sebagai teks contoh/petunjuk.

## Publikasi gratis dengan GitHub Pages
1. Buat akun di https://github.com/
2. Buat repository baru bernama `stit-global-nusantara`.
3. Pilih **Public**.
4. Unggah semua file dalam folder ini ke root repository (bukan folder zip).
5. Buka **Settings → Pages**.
6. Pada **Build and deployment**, pilih **Deploy from a branch**.
7. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
8. Tunggu proses publikasi. Alamat umumnya:
   `https://NAMA-USERNAME.github.io/stit-global-nusantara/`

## Catatan
- Website ini statis. Formulir PMB, berita, dan data mahasiswa belum memiliki sistem database/admin.
- Gunakan Google Forms untuk pendaftaran awal. Jangan unggah NIK atau dokumen pribadi ke repository publik.
- Domain khusus seperti `.ac.id` atau `.com` biasanya memerlukan biaya dan tidak termasuk dalam hosting gratis GitHub Pages.
